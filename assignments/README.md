# AWS Hands-On Assignments



This folder contains the practical AWS projects I completed alongside my AWS revision notes.



The assignments progress from core networking through high availability, content delivery and serverless architecture.



---



## Assignment 1 — VPC and Networking



Built a custom VPC with public and private subnets, route tables, an Internet Gateway, NAT Gateway, EC2 instances, Security Groups and bastion-style access.



\*\*Main AWS services:\*\*



- VPC

- EC2

- Internet Gateway

- NAT Gateway

- Route Tables

- Security Groups

- CloudWatch



[View Assignment 1](./01-vpc-networking/)



---



## Assignment 2 — Application Load Balancer and Auto Scaling



Built a multi-AZ web architecture using private EC2 instances behind an Application Load Balancer with Auto Scaling, Route 53, ACM and HTTPS.



\*\*Main AWS services:\*\*



- EC2

- Application Load Balancer

- Target Groups

- Auto Scaling

- Route 53

- ACM

- Security Groups



[View Assignment 2](./02-alb-auto-scaling/)



---



## Assignment 3 — S3, CloudFront and Route 53



Hosted a static website using Amazon S3, delivered it through CloudFront, configured a custom domain with Route 53 and enabled HTTPS with ACM.



\*\*Main AWS services:\*\*



- Amazon S3

- CloudFront

- Route 53

- ACM



[View Assignment 3](./03-s3-cloudfront-route53/)



---



## Assignment 4 — Serverless API



Built a serverless API using API Gateway, Lambda and DynamoDB with IAM permissions and CloudWatch logging.



\*\*Main AWS services:\*\*



- API Gateway

- DynamoDB

- IAM

- CloudWatch



[View Assignment 4](./04-serverless-api/)
